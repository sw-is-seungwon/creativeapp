모든 기능을 완성할 필요는 없어요. 실제 연결이 어려운 기능은 시뮬레이션으로 표현해도 됩니다.

참고

작성 예시 모아 보기

아래 내용은 작성 방법을 보여주기 위한 가상의 독서 기록 앱 예시입니다. 우리 모둠 앱의 실제 기획 내용이 아니며, 위 입력 칸에 자동 적용되지 않아요.

📝 앱 기획 작성 예시
앱 이름: 한 장의 책장
주요 사용자: 읽은 책을 간단히 기록하려는 사람
해결할 문제: 읽은 책과 감상을 쉽게 정리하기 어렵다
필요한 화면: 책 목록, 기록 작성, 기록 상세
핵심 기능: 책 제목과 한 줄 감상을 입력하면 목록에 추가한다
💬 AI에게 수정 요청하는 예시
“기존의 독서 기록 화면은 유지하고, 기록을 추가하면 책 목록 상단에 바로 나타나도록 수정해 줘.”
🔎 테스트 및 개선 기록 예시
잘 구현한 점: 기록 추가 버튼을 누르면 새 독서 기록이 목록에 표시된다.
개선할 점: 작은 화면에서 글씨가 잘 보이지 않으므로 버튼과 글씨 크기를 키우고 싶다.
🌱 진로 성찰 작성 예시
“UX/UI 디자인 활동이 흥미로웠다. 처음에는 화면을 예쁘게 꾸미는 것만 생각했지만, 사용자가 이해하기 쉬운 버튼 위치와 글씨 크기를 고민하는 일이 중요하다는 것을 알았다.”
03

AI에게 우리 앱 제작 요청하기

위에 작성한 내용을 바탕으로 우리 모둠만의 프롬프트를 완성해 봅시다. 아래 문장을 복사해 AI에게 전달해 보세요. 기존에 그린 화면 설계도 사진을 함께 첨부하면 더 좋아요.

💡 AI가 만든 코드를 어떻게 실행할까요?
AI에게 “완성된 코드를 index.html 파일 하나로 만들어 줘”라고 요청하세요. 코드를 파일로 저장한 뒤 더블클릭하면 브라우저에서 열 수 있어요. 파일을 바로 제공하는 AI라면 HTML 파일을 내려받아 열어도 됩니다.
AI가 이상한 결과를 만들면 처음부터 다시 만들기보다 이렇게 말해 보세요. “기존 화면은 유지하고, [수정할 부분]만 [원하는 방식]으로 바꿔 줘.”

05

우리 모둠의 앱 결과물 제출하기

제작한 앱의 화면을 캡처하거나 HTML 파일을 첨부해 주세요. 두 가지 모두 제출할 수 있습니다.

아이패드나 휴대전화에서는 사진 보관함에서 캡처 이미지를 선택할 수 있어요.
원본 파일이 있는 모둠만 첨부해 주세요. HTML 파일은 300KB 이하로 제출해 주세요.
